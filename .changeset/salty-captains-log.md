Add Captain's Log, an optional prebuilt Pi package that retells the selected conversation's last completed assistant reply as a pirate briefing without changing the original. Install it from Available packages and explicitly enable its plugin; no compilation is required. Its one-button panel creates or reuses a dedicated conversation, preserves previous results, and displays Markdown without executing embedded HTML or loading remote images.
